# Desafio OBT — Listagem de Projetos Espaciais

Aplicação web para listagem e visualização de projetos espaciais internacionais, com busca por nome e paginação.

## Tecnologias

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Mantine](https://mantine.dev/)

## Pré-requisitos

- [Node.js](https://nodejs.org/) — versão LTS recomendada

Verifique se está instalado:
```bash
node -v
npm -v
```

## Instalação

1. Copie a pasta do projeto para sua máquina (sem a pasta `node_modules`)

2. Abra o terminal na pasta do projeto e instale as dependências:
```bash
npm install
```

## Como rodar

```bash
npm run dev
```

Após rodar, acesse no navegador:
```
http://localhost:5173
```

## Funcionalidades

- Listagem de projetos com foto, bandeira do país e status
- Busca por nome do projeto
- Paginação
- Tela de detalhes ao clicar em um projeto
